# Kadro Pusulası

YBS / İİSBF mezunu için 2026 KPSS puanına göre başvurulabilecek kamu ilanlarını listeleyen statik site.

- `index.html` — site
- `ilanlar.json` — ilan listesi (günlük tarama tarafından güncellenir)
- `meta.json` — son tarama zamanı

GitHub Pages ile yayınlanır. Uygunluk değerlendirmeleri ilan özetlerine dayanır; başvurmadan önce resmi ilan metnini kontrol et.
